# IBMDataScienceCapstoneProject
Repository of data, code, notebooks, and presentation for the IBM Data Science Capstone Project.



## Structure of repository

.
├── Data_Wrangling_Webscraping    <- Jupyter notebooks summarising the data acquisition process of the project
├── Exploratory_Data_Analysis     <- Jupyter notebooks summarising data analysis with Pandas/Seaborn, SQL, and Folium 
├── Dashboarding                  <- Python script containing Plotly dashboarding app 
├── Predictive_Analysis           <- Jupyter notebook containing results comparing Machine Learning models recovery of launch success/failure
├── Final_Presentation            <- PDF containing the final presentation slides for the capstone project
├── Data                          <- Data files used in the project
├── .gitignore                    <- Avoids uploading data, credentials, outputs, system files etc
├── LICENCE                       <- License file (GPL v3.0 for this repository)
└── README.md                     <- This file
